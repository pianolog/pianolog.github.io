# 피아노 연습 기록

iPad용 피아노 연습 기록 웹앱(PWA). 기획은 [PLAN.md](PLAN.md), 디자인은 [design/](design/).

## 1단계(MVP)에 들어간 것

- **오늘**: 오늘 연습 시간 / 목표, 연속 연습일, 오늘의 조(5도권 순환 또는 오래 안 친 조), 루틴 진행, 오늘 기록
- **연습 모드**: 메트로놈(탭 템포·박자·세분·강박), 템포 사다리, 항목/세션 타이머, 화면 꺼짐 방지
- **항목 끝내기**: 도달·클린 BPM, 12조(하농 필수), 손, 변형, 별점, 메모 → 다음 번호 / 다음 루틴 항목으로 이어짐
- **기초**: 하농 21–30(BPM 보기 · 12조 커버리지) / 피쉬나 60(a·b) / 스케일·아르페지오, 번호별 상세(12조 매트릭스, 8주 BPM 추이, 변형별 최고)
- **악보 PDF**: iPad 안에 저장, 세로 1쪽 / 가로 2쪽, 좌우 탭·스와이프·블루투스 페달(화살표/PageDown) 넘김, 북마크, 하농·피쉬나 번호별 페이지 연결
- **기록**: 1년 캘린더 히트맵, 날짜별 기록(삭제 가능)
- **설정**: 하루 목표, 오늘의 조 방식, 사다리 간격, 테마, 악보 보관함, JSON 백업 내보내기/가져오기

## 2단계 (레퍼토리 연습 시스템)

- **레퍼토리**: 목록(이름·색) 직접 생성, 곡 추가(마디 수로 구간 자동 나누기), 아카이브, D-day
- **곡 상세**: 오늘 할 구간 자동 추천(복습일·취약·레슨 지적·D-day), 구간별 단계·BPM·다음 복습일
- **구간 집중 연습**: [성공]/[실수], 연속 성공하면 템포 사다리 자동 상승, 실수 계속되면 한 칸 내리기 제안
- **구간 끝내기**: 다시/어려움/됨/쉬움 (Anki 방식, 버튼마다 다음 간격 미리보기)
- **런스루**: 녹음하며 통주, 두 번 탭·페달 길게로 마킹 → 정리 화면에서 파형 듣고 구간 골라 취약 표시
- **레슨노트**: 지적마다 곡·구간 연결, 그 구간 연습 화면에 배너로 표시, 해결 체크
- **오늘 화면**: 고정한 D-day, 오늘의 레퍼토리(루틴에 "레퍼토리" 항목을 넣으면 루틴 안으로 들어감), 최근 레슨
- 기초: 하농 21–30번, 피쉬나 a·b 번호(설정), 스케일·아르페지오 24조 표

## 3단계 (Anki식 간격 복습)

- **4버튼 평가 + 간격 학습**: 구간·카드마다 쉬움 정도(ease)를 기억해 간격 × ease로 늘림, D-day까지 남은 날의 1/3로 상한, 최대 간격 설정
- **오늘 다시**: [다시]는 오늘 큐 끝에 한 번 더, 저장 직후 [되돌리기]
- **고질 구간**: [다시]가 기준 횟수 넘으면 표시 · 잠시 쉬기 · 처음부터 다시
- **하루 한도**: 레퍼토리 복습/새 구간, 기초 책마다 복습/새 카드 · 순서는 끝낸 것 → 복습 → 새 것 → 오늘 다시
- **기초 카드**: 하농 번호×조(120장), 피쉬나 번호, 스케일·아르페지오 조×종류 — 기초 화면·오늘 화면·루틴([간격 복습])에서 시작
- **기록 → 복습**: 30일 복습 예정 그래프, 기억률, 상태별 개수, 평가 분포, 고질 목록

## 실행

Node.js는 `~/.local/node`에 설치돼 있고 `~/.zprofile`에 경로가 추가돼 있음 (새 터미널부터 적용).

```bash
npm run dev
```

- Mac: http://localhost:5173
- 같은 Wi-Fi의 iPad: 터미널에 찍히는 `Network: http://192.168.x.x:5173` 주소로 접속
  (http라서 홈 화면 설치·오프라인은 안 되고, 화면 확인·테스트용)

```bash
npm run build     # dist/ 에 배포용 파일 생성
npm run typecheck # 타입 검사
```

## iPad에 설치해서 쓰기

PWA는 HTTPS 주소가 필요해서 `dist/`를 GitHub Pages·Vercel 같은 곳에 올려야 함.
올린 주소를 iPad Safari에서 열고 → 공유 → **홈 화면에 추가**.

- 기록은 iPad 안(IndexedDB)에만 저장됨 → 설정 → **기록 내보내기**로 주기적으로 iCloud Drive에 백업
- 악보 PDF와 런스루 녹음은 백업에 포함되지 않음 (원본 PDF는 따로 보관)
- 메트로놈 소리가 안 나면 무음 스위치/집중 모드 확인
