# 피아노 연습 기록

iPad에서 쓰는 피아노 연습 기록 웹앱(PWA)입니다. 기획은 [PLAN.md](PLAN.md), 디자인은 [design/](design/), 사용법은 [USER_MANUAL.md](USER_MANUAL.md)에 있습니다.

## 1단계 — 기초 연습

- **오늘**: 오늘 연습 시간과 목표, 연속 연습일, 오늘의 조(5도권 순환 · 오래 안 친 조 · 직접 고르기), 루틴 진행, 오늘 기록
- **연습 모드**: 메트로놈(탭 템포·박자·세분·강박), 템포 사다리, 항목·세션 타이머, 화면 꺼짐 방지
- **자유 연습**: 곡 이름으로 시작. 손(양손·오른손·왼손), 마디 범위(다음 n마디로 넘기기), 연습 방법을 골라 [성공]/[실수]로 칠 때마다 횟수를 세고, 손마다 성공한 가장 먼 마디를 곡별로 기억
- **항목 끝내기**: 도달·클린 BPM, 조(하농은 필수), 손, 변형, 메모를 기록하고 다음 번호나 다음 루틴 항목으로 바로 이어짐
- **기초**: 하농 21–30번(BPM 보기 · 12조 커버리지), 피쉬나 60번(a·b 번호), 스케일·아르페지오 24조 표, 5도권 묶음 연습. 번호별 상세에서 12조 매트릭스, 8주 BPM 추이, 변형별 최고 기록 확인
- **악보 PDF**: iPad 안에 저장, 세로 1쪽 / 가로 2쪽 보기, 좌우 탭·스와이프·블루투스 페달(화살표 / PageDown)로 넘김, 북마크, 하농·피쉬나 번호별 페이지 연결
- **기록**: 1년 캘린더 히트맵, 날짜별 기록(삭제 가능)
- **설정**: 하루 목표, 오늘의 조 방식, 사다리 간격, 테마, 악보 보관함, JSON 백업 내보내기·가져오기

## 2단계 — 레퍼토리 연습

- **레퍼토리**: 목록(이름·색)을 직접 만들고 곡 추가(마디 수로 구간 자동 나누기), 아카이브, D-day
- **곡 찾기**: Open Opus 피아노 곡 약 3,200곡(작곡가 37명)을 앱 안에 넣어 한글·영어로 검색, 곡명을 한글로 바꿔 채움, 곡집 번호·악장 붙이기, 온라인 추가 검색, IMSLP 악보 검색 링크. 목록 새로 만들기: `python3 scripts/build-catalog.py`
- **곡 상세**: 오늘 할 구간 자동 추천(복습일·취약·레슨 지적·D-day 기준), 구간별 단계·BPM·다음 복습일
- **구간 집중 연습**: [성공] / [실수] 기록, 연속 성공하면 템포 사다리가 자동으로 올라가고 실수가 이어지면 한 칸 내리기를 제안. 손(양손·오른손·왼손)과 마디 범위, 연습 방법(암보·리듬 변형·끊어서·페달 없이·느리게)을 골라 치면 한 번 칠 때마다 기록하고, 손마다 친 횟수와 처음부터 이어서 통과한 마디(진도)를 보여 줌
- **런스루**: 녹음하면서 통주하고 두 번 탭·페달 길게 누르기로 걸린 곳 마킹 → 정리 화면에서 파형을 들으며 구간을 골라 취약으로 표시
- **레슨노트**: 지적마다 곡·구간을 연결하면 그 구간 연습 화면에 배너로 표시, 해결 체크
- **오늘 화면**: 고정한 D-day, 오늘의 레퍼토리(루틴에 "레퍼토리" 항목을 넣으면 루틴 안으로 들어감), 최근 레슨

## 3단계 — Anki식 간격 복습

- **4버튼 평가**: 다시 / 어려움 / 됨 / 쉬움. 버튼마다 다음 간격을 미리 보여 줌
- **간격 학습**: 구간·카드마다 쉬움 정도(ease)를 기억해 간격 × ease로 늘림. D-day까지 남은 날의 1/3과 최대 간격을 넘지 않음
- **오늘 다시**: [다시]를 누르면 오늘 목록 끝에 한 번 더 나옴. 저장 직후 [되돌리기] 가능
- **어려운 곳**: [다시]가 기준 횟수를 넘으면 표시. 잠시 쉬기, 처음부터 다시
- **하루 한도**: 레퍼토리 복습·새 구간, 기초 책마다 복습·새 카드. 순서는 끝낸 것 → 복습 → 새 것 → 오늘 다시
- **기초 카드**: 하농 번호×조(120장), 피쉬나 번호, 스케일·아르페지오 조×종류. 기초 화면, 오늘 화면, 루틴([간격 복습])에서 시작
- **기록 → 복습**: 30일 복습 예정 그래프, 기억률, 상태별 개수, 평가 분포, 어려운 곳 목록

## 실행

Node.js는 `~/.local/node`에 설치돼 있고, 경로는 `~/.zprofile`에 추가돼 있습니다. (새 터미널부터 적용)

```bash
npm run dev
```

- Mac: http://localhost:5173
- iPad: 터미널에 나오는 `Network: http://…:5173` 주소로 접속합니다. http 주소라서 홈 화면 설치·오프라인·녹음은 안 되고, 화면 확인과 테스트용으로만 씁니다.

```bash
npm run build
```

`dist/`에 배포용 파일을 만듭니다.

```bash
npm run typecheck
```

타입을 검사합니다.

## iPad에 설치해서 쓰기

PWA는 HTTPS 주소가 있어야 설치됩니다. `main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages에 자동으로 배포합니다. 배포된 주소를 iPad Safari에서 열고 공유 → **홈 화면에 추가**를 누르세요.

- 기록은 iPad 안(IndexedDB)에만 저장됩니다. 설정 → **기록 내보내기**로 iCloud Drive에 자주 백업하세요.
- 악보 PDF와 런스루 녹음은 백업에 들어가지 않습니다. 원본 PDF는 따로 보관하세요.
- 메트로놈 소리가 나지 않으면 무음 모드와 집중 모드를 확인하세요.
